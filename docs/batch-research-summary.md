# 批量研究结果中文摘要

先通过离线批量 runner 生成结果 JSON，再生成便于复核的 Markdown：

```sh
python -m scripts.batch_research_summary --input batch-result.json --output batch-summary.md --max-rows 20
```

命令只读取本地结果，生成一个中文摘要文件。显示总任务数、重新计算的成功／失败
数量、每个展示任务的输入 SHA-256、完整计划 SHA-256、历史方向、研究结论及失败
原因。最多显示 100 项，默认 20 项，按确定性计划代码顺序排列，不构成排名；明确
列出省略任务数。每项最多显示 3 条事实，每条归一化后最多 160 字，省略条数和字数
会明示。HTML 与 Markdown 控制字符经过转义，不把输入内容作为链接或 HTML 执行。

摘要生成前严格检查已知版本的完整字段集合、哈希格式、股票及任务身份、确定性
顺序、输入哈希状态、失败原因、证据日期与数量以及所有未核验标志。成功计数和
整包状态按任务实际状态重算并比较；未知字段、重复 JSON 键、篡改计数、不一致
状态和任何验证／预测／建议标志提升均拒绝。计划由股票集合及分析日期重建后检查
计划 ID 与 SHA-256。受支持的成功研究结论固定为“证据不足，暂不形成方向性投资
结论”，不接受替换的推荐文案。

这些检查验证结果包内部一致性，不代表重新计算价格、重新生成原始摘要或验证
输入哈希对应的原始报告。输入原件并未包含在结果中，输入哈希仅检查格式和状态
关系；发布者、来源真实性、历史时点可用性始终未核实。分析截止日期不证明数据
当时已公开。摘要不输出股票排名、目标价或买卖建议。

输入上限 20 MiB，并沿用 runner 的 JSON 深度、节点与编码预算限制。输出采用
原子替换，拒绝覆盖输入文件或符号链接目标。校验失败不会替换已有摘要。不联网、
不调用模型、付费接口、券商或交易功能。

测试：`python -m unittest tests.test_batch_research_summary -v`。
