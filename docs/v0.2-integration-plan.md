2. Review #3 and #5. Preserve the explicit unverified-source defaults in run manifests.
3. Review #7 and #6 independently. Keep date-only A-share announcements ineligible for same-day point-in-time claims until original publication times are independently verified.

6. Run full CI on the combined branch. Use synthetic/offline fixtures. Do not trigger paid LLM analysis or broker access.
7. Perform a separate manual smoke test with intentionally synthetic data. Confirm metadata does not falsely claim source authenticity, and report artifact checks fail when output is absent.
8. Request human review before any merge to `main`.

## Contract and risk checklist

- [ ] `python -m unittest discover -s tests -v` passes on the combined branch.
- [ ] CLI import of `scripts/analyze.py` and module import both work.
- [ ] Generated report path and artifact upload path match exactly.
- [ ] Missing/empty report causes a nonzero validation exit code.
- [ ] No API tokens or personal credentials appear in logs or committed files.
- [ ] Sources are marked unverified unless validated against original publications.
- [ ] Date-only announcements do not pass as timestamp-verified evidence.
- [ ] SEC acceptance time uses US Eastern timezone, including daylight-saving transitions.
- [ ] All time cutoffs are explicit and timezone-aware.
- [ ] No automatic merge, trading action, or unattended paid inference.

## Release gate

Do not label v0.2 production-ready until the combined branch has passed CI,
report generation has been validated against a known fixture, and data
provenance limitations are documented. Existing isolated CI successes are
necessary but insufficient.
